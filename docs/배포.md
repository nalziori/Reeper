# 배포

배포처는 두 곳을 준비했다. 기본은 Render 무료(`render.yaml`), 유료로 옮길 때는 Cloudflare Containers(`deploy/cloudflare`)다. 아래는 컨테이너 하나로 화면과 API를 함께 내보내는 기준이다. Render에는 2026-11-17에 실제로 배포했다(아래 "실제 배포 기록"). Cloudflare에는 배포하지 않았다.

## 환경변수

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `OPENAI_API_KEY` | 없음 | 없으면 가짜 LLM(고정 규칙)으로 뜬다. 서버 환경변수에만 둔다 |
| `OPENAI_MODEL` | `gpt-6.1-terra` | 사용할 모델 |
| `LLM_DAILY_LIMIT` | `300` | 하루 전체 LLM 호출 상한. 넘으면 고정 양식과 버튼 입력으로 계속 진행한다 |
| `PORT` | `8000` | 컨테이너가 듣는 포트 |
| `TZ` | 없음(UTC) | 하루 호출 수를 세는 날짜의 시간대. 배포 설정은 `Asia/Seoul` |
| `MAX_BODY_BYTES` | `262144`(256KB) | 요청 본문 상한. 넘으면 413 |
| `ALLOW_UPLOAD` | 넣지 않음 | `1`이면 계약서 사진 읽기를 켠다. 합성(가상) 계약서로만 쓴다(운영사무국 답, 2026-11-16). 켜면 사진 한 장에 LLM 호출 한 번이 든다 |
| `UNLOCK_KEY` | 없음 | 심사용 잠금. 넣으면 `https://…/unlock/<값>`으로 들어온 사람만 실제 LLM을 쓰고, 공개 주소는 가짜 LLM으로 돈다. 공개 주소로 들어온 사람이 하루 상한을 다 쓰지 못하게 한다. 비우면 잠금이 꺼져 키가 있는 한 모두 실제 LLM을 쓴다. 서버 환경변수에만 둔다 |

## 심사용 잠금(UNLOCK_KEY)

공개 주소는 로그인이 없어 누구나 모델을 부를 수 있다. 한 사람이 하루 상한(100회)을 다 쓰면 그 뒤로는 가짜 LLM으로만 돈다. `UNLOCK_KEY`를 넣으면 비밀 주소로 들어온 사람만 실제 모델을 쓴다.

- 대시보드에서 `UNLOCK_KEY`에 아무나 모를 값을 넣는다(예: 긴 무작위 문자열).
- 심사위원에게는 `https://<배포 주소>/unlock/<그 값>`을 보낸다. 그 주소로 들어가면 쿠키가 생기고 앱으로 넘어가며, 이후 그 브라우저에서는 실제 모델을 쓴다.
- 공개 주소(`https://<배포 주소>/`)로 그냥 들어가면 가짜 LLM으로 돈다. 흐름과 화면은 똑같이 보인다.
- 값은 주소에 들어가므로 접속 기록·브라우저 방문 기록에 남는다. 심사가 끝나면 대시보드에서 값을 바꾸거나 지운다. 돈은 월 상한이 따로 막는다.
- `UNLOCK_KEY`를 비워 두면(기본) 잠금이 꺼져, 키가 있으면 모두 실제 모델을 쓴다(지금까지의 동작).

## 빌드와 실행

```
docker build -t reeper .
docker run -p 8000:8000 -e OPENAI_API_KEY=... -e LLM_DAILY_LIMIT=300 reeper
```

키 없이 `docker run -p 8000:8000 reeper`만 해도 뜬다. 컨테이너는 비루트 사용자로 돌고 `/api/health`로 HEALTHCHECK한다.

## Render 무료 (기본)

저장소 루트의 `render.yaml`(Blueprint)로 만든다. Render 대시보드에서 New → Blueprint로 이 저장소를 고르면 `main`에 병합되고 CI가 통과할 때마다 자동으로 배포된다(`autoDeployTrigger: checksPass`).

무료 플랜은 메모리 512MB, CPU 0.1이다. 로컬에서 같은 제한(`docker run --memory 512m --cpus 0.1`)으로 띄워 보면 메모리는 약 42MB를 쓰고, 서버가 뜨는 데 약 43초 걸리며, 샘플 계약으로 종결까지 간다(가짜 LLM, 2026-11-17). 배포 직후나 잠들었다 깰 때는 이만큼 기다린다.

- 결제수단은 등록하지 않는다. 그러면 무료 한도(월 750시간, 대역폭)를 넘었을 때 과금 대신 그달 남은 기간 정지된다.
- 15분 동안 요청이 없으면 잠들고 깨는 데 약 1분 걸린다. Render 계정을 만든 사람이 무료 모니터링 서비스(UptimeRobot 등)에 10분마다 `GET /api/health`를 부르도록 등록해 깨워 둔다(한 달 약 720시간). `/api/health`는 계약 내용을 담지 않는다.
- 서버 시간대는 `TZ=Asia/Seoul`이다. 하루 호출 수는 한국 자정에 0이 된다.

## 배포 전에 정할 것

| 위험 | 내용 | 대응 |
|---|---|---|
| 돈이 나가는 키가 공개 링크에 걸림 | 링크를 아는 누구나 하루 상한까지 LLM을 부를 수 있다. 하루 최대 비용(추정): 사진 읽기 꺼짐이면 가장 비싼 호출이 전략(약 0.005달러)이라 상한 100이면 약 0.5달러, 300이면 약 1.5달러. 사진 읽기를 켜면 1회 약 0.007달러라 100이면 약 0.7달러, 300이면 약 2.1달러(eval 결과 5절) | 키 주인의 동의를 받고 넣는다. 하루 상한은 100이다(키 주인 결정, #56 리뷰). 바꾸려면 키 주인과 정한다. 키 쪽(OpenAI 프로젝트)에도 월 예산 상한을 건다 |
| 상한이 생각보다 자주 0이 됨 | 호출 수는 프로세스 메모리에 있어 재배포·재시작·잠들기마다 0이 된다. Render는 `main`에 병합될 때마다 다시 배포하므로, 하루에 병합이 N번이면 그날 최대 호출은 상한 × (N+1)이다 | 배포 설정의 상한은 100이다. 핑으로 깨워 둔다. 실제 키를 넣은 뒤에는 `autoDeployTrigger`를 `off`로 바꿔 손으로 배포한다. 배포하는 순간 서비스가 잠깐 내려갔다 뜨므로 심사 시간에는 배포하지 않는다. 키 쪽(OpenAI 프로젝트) 월 예산 상한이 최종 안전장치다 |
| 사진 읽기 | 켜면 누구나 실제 계약서를 올릴 수 있다. 운영사무국 답은 가상 계약서만이다 | 기본은 끈다(`ALLOW_UPLOAD`를 넣지 않음). 켜려면 먼저 화면에 "가상 계약서만 올려 주세요" 안내를 넣는다 |
| 계정과 키 관리 | 누구 계정에 만들고 누가 키를 넣는지 | 계정을 만드는 사람이 키를 대시보드 환경변수에만 넣는다. 저장소·채팅·PR에 키를 적지 않는다 |

## Cloudflare Containers (유료로 옮길 때)

`deploy/cloudflare`의 Worker가 모든 요청을 컨테이너 하나(`getContainer`, `max_instances: 1`)로 넘긴다. 이미지는 저장소 루트의 `Dockerfile`을 그대로 쓴다.

필요한 것: Workers 유료 플랜(Containers와 Durable Objects), 로컬 Docker(배포 때 이미지를 빌드한다), Cloudflare 계정 로그인.

```
cd deploy/cloudflare
npm ci
npx wrangler login
npx wrangler secret put OPENAI_API_KEY   # 실제 LLM을 쓸 때만. 없으면 가짜 LLM으로 뜬다
npm run deploy
```

- `LLM_DAILY_LIMIT`, `OPENAI_MODEL`은 `wrangler.jsonc`의 `vars`에서 바꾼다. Worker가 컨테이너 환경변수로 넘긴다.
- `ALLOW_UPLOAD`는 넘기지 않는다. 사진 읽기는 꺼진 채로 뜬다.
- Worker 로그(`observability`)는 끈다. 서버와 같이 요청 내용을 남기지 않는다.
- 컨테이너는 2시간 동안 요청이 없으면 잠든다. 잠들었다 깨면 하루 호출 수가 0으로 돌아간다(아래 알려진 제약). 첫 요청은 컨테이너가 뜨는 몇 초가 더 걸린다.
- 배포 전 점검: `npm run check`(이미지 빌드 포함 dry-run). Docker 없이 Worker만 보려면 `npx wrangler deploy --dry-run --containers-rollout=none`.

## 배포 직후 확인

- [ ] `GET /api/health`가 `ok: true`이고 `llm`이 기대한 값(`OpenAILLM` 또는 `FakeLLM`), `calls_left`가 `LLM_DAILY_LIMIT`와 같다. `upload`는 `false`다.
- [ ] 화면에서 샘플 계약으로 종결까지 3분 안에 간다(데스크톱, 모바일).
- [ ] 그냥 열면 시연 조작(사장 답, 날짜 건너뛰기)이 보이지 않고, 주소에 `?demo`를 붙이면 보인다. 심사용 링크에는 `?demo`를 붙인다.
- [ ] 키 없이도 서버가 뜨고 같은 흐름이 끝난다.
- [ ] 실제 키를 넣었다면 답장 읽기 한 번, 전략 한 번을 해서 `llm_fallback`이 뜨지 않고 `/api/health`의 `calls_left`가 그만큼 줄었는지 본다. 컨테이너 안에서 실제 모델을 부르는 첫 확인이다(유료 호출 몇 회).
- [ ] 256KB를 넘는 POST는 413이다.

## 아직 확인하지 않은 것

- 배포 주소에서 모바일 폭의 흐름(로컬 빌드는 확인), 깨워 두는 핑, 심사 기간의 자동 배포 끄기.
- 사진 읽기를 켠 배포(`ALLOW_UPLOAD=1`). 로컬에서만 확인했다.
- Render와 Cloudflare 자체의 동작(무료 한도, 잠들기). 각 서비스 문서를 읽은 내용이다.

## 알려진 제약

- 일일 호출 수는 `agent.py`의 `OpenAILLM.usage`, 즉 프로세스 메모리에 있다. 재시작·재배포·잠들기 뒤 0으로 돌아가고 인스턴스마다 따로 센다. 날짜는 서버 시간대 기준이다(`TZ`). 인스턴스를 1개로 고정해야 상한이 의미가 있다. 늘리려면 공유 저장소가 필요하다.
- 서버는 사건과 계약 내용을 저장하지 않는다. 사건은 화면이 보관하고 요청에 실어 보낸다. 로그에도 남기지 않는다. 그래서 서버를 재시작하거나 교체해도 사건은 사라지지 않는다.
