# Reeper 기획안

작성일: 2026-11-14 / 대회: 2026 대한민국 청년 CAREER FAIR AI 해커톤 / 제출 마감: 2026-11-23 17:00

**상태: 초안이다.** 법령 내용은 조사로 확인한 범위이며, "확인 필요"로 표시한 항목은 원문을 직접 봐야 한다. 확인된 규칙은 [환불 규칙](환불_규칙.md)에, 분담과 일정은 [개발 계획](개발_계획.md)에 둔다.

## 한 줄 소개

헬스장·PT·필라테스를 중도해지하려는 청년의 환불 건을 처음부터 끝까지 맡아, 받을 금액을 계산하고 해지 의사가 도달한 날짜와 기한을 추적하며 업체 반응에 따라 다음 단계를 정해 주는 에이전트다.

## 문제 정의

**미룰수록 환불액이 줄어드는데, 근거와 기한을 끝까지 챙겨 줄 담당자가 없다.**

- 공정위 고시상 공제 기준은 해지 의사가 업체에 도달한 날이다. 한 번도 가지 않았어도 개시일 이후 지난 날짜는 이용한 것으로 본다.
- 그래서 전화가 부담돼 며칠 미루면 그만큼 돈이 줄어든다.
- 업체가 답하지 않거나 "방문해서 얘기하자"로 돌리면 대부분 거기서 멈춘다.
- 팀원의 실제 경험과 간이 설문(10명 이상)으로 "미룬 기간과 포기한 금액"을 확인해 소개서에 싣는다.

## 사건의 흐름

| 단계 | 에이전트가 하는 일 | 사람이 하는 일 |
|---|---|---|
| 1. 접수 | 계약서 사진에서 결제액, 기간, 개시일, 특약을 추출 | 불확실한 값 확인 |
| 2. 계산 | 경과일 기준 이용분과 10% 위약금을 공제한 환불액 계산, 하루 미룰 때 줄어드는 금액 표시 | 목표 금액과 최저 수용선 설정 |
| 3. 통지 | 근거와 계산이 들어간 해지 요청 문안 작성 | 본인 휴대폰에서 직접 발송 |
| 4. 추적 | 도달일을 기록하고 답변 기한을 관리 | 답장이 오면 붙여넣기 |
| 5. 대응 | 답장을 분류하고 다음 행동을 결정: 반박, 합의 확인, 재요청, 에스컬레이션 | 발송 승인 |
| 6. 무응답 | 기한이 지나면 재요청, 그다음 내용증명과 1372 신청서 준비 | 제출 승인 |
| 7. 종결 | 합의 내용 확인 문안과 사건 요약 | 입금 확인 |

무응답은 실패가 아니라 정상 경로다. 통화 없이도 끝까지 갈 수 있게 설계한다.

## 에이전트 구조

사건 상태(금액, 도달일, 기한, 주고받은 내용, 현재 단계)를 쥐고, 새 일이 생길 때마다 도구를 골라 쓴다.

| 도구 | 담당 | 설명 |
|---|---|---|
| 계약서 추출 | AI | 사진에서 값과 원문 위치를 뽑고, 자신 없는 값은 표시 |
| 환불액 계산 | 코드 | 경과일, 개시 전 해지, 횟수제를 단위테스트로 검증 |
| 근거 조회 | 코드 | 조문 번호가 적힌 검증된 표에서만 가져옴 |
| 답장 분류 | AI | 무시, 정상가 주장, 방문 요구, 일부 금액 제시, 수용 등으로 분류하고 금액 추출 |
| 수용선 판정 | 규칙 | 제시액을 법정액과 사용자 수용선에 비교 |
| 기한 확인 | 코드 | 도달일로부터 경과 시간을 계산 |
| 문안 작성 | AI | 고정 양식에 값과 근거를 채움 |
| 승인 요청 | 규칙 | 발송·제출 전에 사용자 확인 |

AI가 꼭 필요한 곳은 추출, 분류, 문안 세 군데이고 나머지는 코드라는 점을 먼저 밝힌다. "계산은 코드, 판단은 AI, 발송은 사람"이 설명의 뼈대다.

## 실제와 모의의 경계

| 오늘 실제로 되는 것 | 시연용 모의 |
|---|---|
| 계약서 추출과 환불액 계산 | 업체의 답장 (심사위원이 직접 입력) |
| 해지 요청 문안, 문자 앱으로 넘기기 | 며칠 경과 (시간 건너뛰기 버튼) |
| 답장 붙여넣기 후 분류와 다음 행동 제안 | |
| 내용증명과 1372 신청서 초안 | |

에이전트가 문자를 대신 보내거나 답장을 직접 읽는다고 주장하지 않는다. 국내 문자 발송은 발신번호 사전등록이 필요하고, 답장은 사용자 휴대폰으로 오기 때문이다.

## 심사위원 3분 체험

1. 링크 접속, 로그인과 마이크 없음.
2. 샘플 계약서 선택 → 추출 결과와 환불액 확인.
3. 해지 요청 문안 승인.
4. 심사위원이 사장 역할을 맡아 버튼(무시, 정상가 주장, 방문 요구, 일부 금액 제시)이나 직접 입력으로 답한다.
5. 에이전트가 근거를 들어 대응하거나, "3일 경과"를 누르면 재요청과 에스컬레이션 문서로 넘어간다.
6. 타임라인 화면에서 발송, 도달, 기한, 재요청, 종결을 한눈에 본다.

심사위원이 직접 공격하는 구조라 AI끼리 주고받는 연극으로 보이지 않는다.

## 안전장치

- **발신자는 항상 사용자 본인**이고 서비스 명의로 업체와 교섭하지 않는다.
- **문서는 고정 양식에 값 채우기**로 만들고, 표에 없는 근거는 문장에 넣지 못한다.
- **최종 판단은 1372 소비자상담센터**로 연결하고 "일반적인 기준 안내"로 표시한다.
- **표에 없는 주장이 오면** 단정하지 않고 확인이 필요하다고 답한다.
- **시연은 가상 계약서만** 사용한다.
- 변호사법 제109조와의 경계 때문에 위 세 가지(본인 발신, 고정 양식, 공식 상담 연결)를 소개서에 명시한다.

## 차별점

- 환불 계산 글과 계산기는 계산에서 멈춘다. 여기는 도달일과 기한을 추적하고 다음 단계로 넘긴다.
- 내용증명 작성 서비스는 문서 한 장을 만든다. 여기는 그 문서가 필요해지는 시점까지 사건을 끌고 간다.
- 대신 연락해 주는 AI는 국내 헬스장에서 스팸으로 끊긴 사례가 보도됐다. 여기는 사용자 본인이 보내므로 그 문제가 없다.
- 해외의 대행형 서비스(Pine AI, DoNotPay)는 "결국 사용자가 직접 했다", "정확도를 검증하지 않았다"는 비판을 받았다. 그래서 평가 수치를 공개한다.

## 수치 증거

| 평가 | 방법 | 측정값 |
|---|---|---|
| 추출·계산 | 정답을 아는 가상 계약서 20~30건 | 항목별 정답률, 환불액 일치율 |
| 답장 분류 | 업체 답장 예시 30개 | 분류 정확도, 금액 추출 정확도 |
| 근거 준수 | 전체 응답 검사 | 표 밖 근거 인용 횟수(목표 0건) |
| 부당 합의 차단 | 수용선 미만 제시 사례 | 경고 비율 |
| 비교 | 같은 사례를 계약 정보 없는 일반 LLM에 입력 | 금액 오류와 근거 오류 건수 |
| 비용 | 사건 1건당 호출 수 | 원 단위 |

## 예상 점수와 다른 안과의 비교

독립 평가자의 추정이며 실제 심사 결과가 아니다.

| 안 | 예상 점수 | 9일 내 완성 |
|---|---|---|
| 환불 건 담당 에이전트 (이 안) | 64~84 | 75~85% |
| 어려운 통화 코파일럿 | 59~80 | 필수 전부는 30~40% |
| NCS 직무 성장 시뮬레이션 | 51~68 | 높지만 천장이 낮음 |

본선 진출 조건으로 꼽힌 세 가지는 심사위원 단독 3분 완주, 수치 증거, 실제와 모의의 경계 공개다.

## 아직 확인이 필요한 것

- **대회 제출물 형식과 개인정보 규칙**: 운영사무국에 문의한다. 배포 링크가 필수인지가 핵심이다.
- **고시 별표 원문**: 개시 전 해지 금액과 횟수제 PT의 단위대금 산정 방식.
- **"실결제가 기준"의 예외**: 계약서에 단위요금이 명시되었거나 소비자 서면동의가 있으면 달라질 수 있다.
- **답변 기한과 환급 기한의 일수**: 법령 원문에서 확인해 근거 표에 넣는다.
- **팀 합의**: 통화 코파일럿 기획안의 "직접 말하게 돕는다"는 취지가 이 안에서는 빠진다.
