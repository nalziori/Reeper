# 환불 규칙

계산 함수와 문안이 인용하는 법적 근거를 모아 둔다. **이 문서에 "확인됨"으로 적힌 내용만 코드와 문안에 쓴다.** 나머지는 원문을 직접 읽고 확인한 사람과 날짜를 적은 뒤 옮긴다.

이 문서는 일반적인 기준을 정리한 것이며 법률 자문이 아니다.

## 확인된 것

조사 과정에서 출처를 통해 확인한 내용이다. 코드에 넣기 전에 담당자가 원문을 한 번 더 읽는다.

| 내용 | 근거 | 상태 |
|---|---|---|
| 계속거래 소비자는 계약기간 중 언제든 해지할 수 있다 | 방문판매 등에 관한 법률 제31조 | 확인됨 (조사), 원문 재확인 필요 |
| 과다한 위약금 청구 금지, 차액 환급, 지연 시 배상 | 같은 법 제32조 | 확인됨 (조사), 원문 재확인 필요 |
| 헬스·피트니스업, 요가·필라테스업이 고시 적용 업종이다 | 계속거래 등의 해지·해제에 따른 위약금 및 대금의 환급에 관한 산정기준 (공정위 고시) | 확인됨 (조사), 원문 재확인 필요 |
| 위약금은 총계약대금의 10%를 넘지 못한다 | 같은 고시, 공정위 의결서 인용 | 확인됨 (조사), 원문 재확인 필요 |
| 공제 기준 시점은 해지 의사표시가 사업자에게 도달한 시점이다 | 같은 고시 제5조 제1항 | 확인됨 (조사), 원문 재확인 필요 |
| 직접 이용하지 않았어도 기한이 도래해 이용할 수 있었으면 공급된 것으로 본다 | 같은 고시 제5조 제1항 | 확인됨 (조사), 원문 재확인 필요 |
| 소비자분쟁해결기준(체육시설업)은 개시 후 해지 시 이용일수 금액과 총 이용금액의 10%를 공제한다 | 소비자분쟁해결기준 | 확인됨 (조사), 원문 재확인 필요 |
| 소비자분쟁해결기준은 합의 권고 기준이고, 강행 근거는 방문판매법이다 | 보도·기고 | 확인됨 (2차 자료) |

## 확인이 필요한 것

아래는 아직 원문을 보지 못했다. 확인 전에는 계산과 문안에 쓰지 않는다.

| 항목 | 왜 필요한가 | 볼 곳 |
|---|---|---|
| 개시 전 해지 시 공제 금액 | 계산 함수의 분기 | 고시 별표 |
| 횟수제 PT의 단위대금 산정 방식 | 횟수제 계산 | 고시 별표 |
| 이용분을 일할로 계산하는 정확한 방식 | 기간제 계산의 기본식 | 고시 별표, 소비자분쟁해결기준 |
| 할인가·이벤트가로 결제한 경우의 기준 금액 | "정상가로 차감한다"는 업체 주장에 대한 대응 | 고시, 공정위 심결례 |
| 답변을 기다릴 기한과 환급 기한의 일수 | 기한 추적과 재요청 시점 | 방문판매법 제32조, 시행령 |
| 사은품·부대서비스(운동복, 락커 등) 공제 | 업체가 자주 공제하는 항목 | 고시 |
| 카드 수수료 공제 가능 여부 | 업체가 자주 주장하는 항목 | 공정위 약관 시정 사례 |

## 단정하면 안 되는 것

- **"정상가 차감은 무효"라고 단정하지 않는다.** 계약서에 단위요금이 명시되어 있거나 소비자의 서면 동의가 있으면 달리 볼 수 있다는 상담 사례가 있다. 문안은 "실제 결제금액 기준으로 계산해 달라"는 요청으로 쓰고, 다툼이 있으면 1372 상담으로 연결한다.
- **"한 번도 안 갔으면 대부분 돌려받는다"고 쓰지 않는다.** 개시일 이후 지난 날짜는 이용한 것으로 본다.
- **환불을 "받을 수 있다"고 확정하지 않는다.** "일반적인 기준에 따른 예상 금액"으로 표시한다.

## 계산식 (초안, 확인 전)

기간제 회원권, 개시 후 해지 기준이다. 일할 계산 방식이 확인되면 확정한다.

```
이용분 = 총 결제금액 × (개시일부터 해지 의사 도달일까지의 일수 ÷ 총 계약일수)
위약금 = 총 결제금액 × 10%
환불액 = 총 결제금액 − 이용분 − 위약금   (0보다 작으면 0)
```

예시: 90일 60만 원 회원권을 개시 10일째에 해지하면 이용분 약 66,700원, 위약금 60,000원, 환불액 약 473,300원이다.

## 반론 유형과 대응 근거 (초안)

| 업체 답장 유형 | 대응 방향 | 인용할 근거 |
|---|---|---|
| 무응답 | 기한 경과 후 재요청, 이어서 내용증명 | 방문판매법 제31조, 제32조 |
| "환불 불가 상품이다" | 계속거래는 언제든 해지할 수 있음을 안내 | 방문판매법 제31조 |
| "정상가 기준으로 차감한다" | 실제 결제금액 기준 계산을 요청, 다툼 시 1372 연결 | 확인 필요 |
| "방문해야 처리된다" | 해지 의사는 이미 도달했음을 알리고 서면 처리를 요청 | 고시 제5조 제1항 |
| 법정액보다 적은 금액 제시 | 계산 내역을 제시하고 차액을 요청, 수용선 미만이면 경고 | 고시 (10% 상한) |
| 법정액 이상 제시 또는 수용 | 합의 내용 확인 문안으로 넘어감 | 없음 |
| 표에 없는 주장 | 단정하지 않고 "확인 후 다시 연락드리겠다"로 답함 | 없음 |
