# 환불 규칙

계산 함수와 문안이 인용하는 법적 근거를 모아 둔다. **이 문서에 "확인됨"으로 적힌 내용만 코드와 문안에 쓴다.** 나머지는 원문을 직접 읽고 확인한 사람과 날짜를 적은 뒤 옮긴다.

이 문서는 일반적인 기준을 정리한 것이며 법률 자문이 아니다.

## 확인된 것

조사 과정에서 출처를 통해 확인한 내용이다. 코드에 넣기 전에 담당자가 원문을 한 번 더 읽는다.

| 내용 | 근거 | 상태 |
|---|---|---|
| 계속거래 소비자는 계약기간 중 언제든 해지할 수 있다 | 방문판매 등에 관한 법률 제31조 | 확인됨 (조사), 원문 재확인 필요 |
| 과다한 위약금 청구 금지, 차액 환급, 지연 시 배상 | 같은 법 제32조 | 확인됨 (조사), 원문 재확인 필요 |
| 헬스·피트니스업, 요가·필라테스업이 고시 적용 업종이다 | 계속거래 등의 해지·해제에 따른 위약금 및 대금의 환급에 관한 산정기준 (공정위 고시) 제3조제1항제3호 | 확인됨 (정본, 2026-11-18). 아래 확인 기록과 정본 원문 |
| 위약금은 총계약대금의 10%를 넘지 못한다 | 같은 고시, 공정위 의결서 인용 | 확인됨 (조사), 원문 재확인 필요 |
| 공제 기준 시점은 해지 의사표시가 사업자에게 도달한 시점이다 | 같은 고시 제5조 제1항 | 확인됨 (조사), 원문 재확인 필요 |
| 직접 이용하지 않았어도 기한이 도래해 이용할 수 있었으면 공급된 것으로 본다 | 같은 고시 제5조 제1항 | 확인됨 (조사), 원문 재확인 필요 |
| 소비자분쟁해결기준(체육시설업)은 개시 후 해지 시 이용일수 금액과 총 이용금액의 10%를 공제한다 | 소비자분쟁해결기준 | 확인됨 (조사), 원문 재확인 필요 |
| 소비자분쟁해결기준은 합의 권고 기준이고, 강행 근거는 방문판매법이다 | 보도·기고 | 확인됨 (2차 자료) |

## 확인이 필요한 것

아래는 아직 원문을 보지 못했다. 확인 전에는 계산과 문안에 쓰지 않는다.

| 항목 | 왜 필요한가 | 볼 곳 |
|---|---|---|
| 개시 전 해지 시 공제 금액 | 계산 함수의 분기 | 고시 별표 |
| 횟수제 PT의 단위대금 산정 방식 | 횟수제 계산 | 고시 별표 |
| 이용분을 일할로 계산하는 정확한 방식 | 기간제 계산의 기본식 | 고시 별표, 소비자분쟁해결기준 |
| 할인가·이벤트가로 결제한 경우의 기준 금액 | "정상가로 차감한다"는 업체 주장에 대한 대응 | 고시, 공정위 심결례 |
| 답변을 기다릴 기한과 환급 기한의 일수 | 기한 추적과 재요청 시점 | 방문판매법 제32조, 시행령 |
| 사은품·부대서비스(운동복, 락커 등) 공제 | 업체가 자주 공제하는 항목 | 고시 |
| 카드 수수료 공제 가능 여부 | 업체가 자주 주장하는 항목 | 공정위 약관 시정 사례 |

## 단정하면 안 되는 것

- **"정상가 차감은 무효"라고 단정하지 않는다.** 계약서에 단위요금이 명시되어 있거나 소비자의 서면 동의가 있으면 달리 볼 수 있다는 상담 사례가 있다. 문안은 "실제 결제금액 기준으로 계산해 달라"는 요청으로 쓰고, 다툼이 있으면 1372 상담으로 연결한다.
- **"한 번도 안 갔으면 대부분 돌려받는다"고 쓰지 않는다.** 개시일 이후 지난 날짜는 이용한 것으로 본다.
- **환불을 "받을 수 있다"고 확정하지 않는다.** "일반적인 기준에 따른 예상 금액"으로 표시한다.

## 계산식 (2026-11-15 팀 결정)

기간제 회원권 기준이다. 아래 다섯 가지는 규정이 있으면 규정대로, 없으면 조정 사례를 따른다.

| 항목 | 결정 | 근거 |
|---|---|---|
| 1. 계산 단위 | 기간으로 정한 계약은 일 단위로 일할한다. 계약서에 월 단위로 적혀 있어도 개월이 아니라 날짜로 센다(2026-11-20 변경). 횟수로 정한 계약(PT·레슨)은 횟수로 센다. 적혀 있지 않으면 일 단위 | 고시 제2조제3호, 제5조제1항. 월 단위 일할은 아래 "월 단위 결정 변경"의 출처 |
| 2. 부가상품(사은품) | 계약서에 가액이 적혀 있을 때만 공제한다 | 고시 제5조제1항, 제6조제2항 |
| 3. 보증금 | 별도 약정이 없으면 전액 환급한다 | 고시 제5조제2항 |
| 4. 해지 의사 도달 당일 | 이용일에 넣는다. 개시일도 첫날부터 센다 | 규정 없음. [한국소비자원 조정 사례](https://www.kca.go.kr/odr/bj/br/osBjDecisionExamDetW.do?brdId=00000007&dataStts=Y&seq=1001711832)가 해지일을 이용일에 넣어 21일로 계산. 소비자24 [13984](https://www.consumer.go.kr/user/ftc/consumer/trublmdatcase/116/selectTrublMdatCaseView.do?trublMdatCaseSn=13984)(2024, 2024. 3. 4.~8. 2. = 152일)와 [13542](https://www.consumer.go.kr/user/ftc/consumer/trublmdatcase/116/selectTrublMdatCaseView.do?trublMdatCaseSn=13542)(2020, 1. 28.~3. 6. = 39일)도 개시일과 해지 요청일을 모두 넣었다. 반대로 [11731](https://www.consumer.go.kr/user/ftc/consumer/trublmdatcase/116/selectTrublMdatCaseView.do?trublMdatCaseSn=11731)(2007)은 "통지한 날의 전날까지"로 셌다(167일). 아래 "날짜 세기와 끝전 원문 대조" |
| 5. 원 단위 끝전 | 이용분의 원 미만을 버린다. 최종 환불액은 따로 깎지 않는다 | 규정 없음. 같은 조정 사례가 이용금액 원 미만 절삭. 소비자24 11731·13984·13542·13340·12224도 이용분의 원 미만을 버렸다. 11731·12224·13340은 최종 환급액의 1,000원 미만도 버렸지만, 사용자 손해라 따르지 않는다 |

```
이용분 = 총계약대금 × (개시일부터 해지 의사 도달일까지의 일수, 양 끝 포함 ÷ 총 계약일수)   원 미만 버림
회 단위면 이용분 = 총계약대금 × (이용 횟수 ÷ 총 횟수)   원 미만 버림
위약금 = 총계약대금 × 10%
환불액 = 총계약대금 − 이용분 − 부가상품 가액(계약서에 있을 때) − 위약금 + 보증금   (0보다 작으면 0)
```

예시: 90일 60만 원 회원권을 개시 10일째에 해지하면 이용분 66,666원, 위약금 60,000원, 환불액 473,334원이다.

- 4·5번은 조정 사례 한 건(2013년, 소비자분쟁해결기준 2011년판 적용)에 기댄다. 이 사례는 `data/rules.json`에 없어서 문안에 근거로 쓰지 않는다(`AGENTS.md:8`). 통화 카드도 사례를 들지 않고, 날짜로 계산할 때는 도달 당일도 이용일에 넣는다는 계산 방식만 말한다(2026-11-20 C, `call_card.txt:16`). 당일 포함 여부는 고시 원문에 명시돼 있지 않아(아래 확인 기록) 팀이 정한 계산 방식이다. 앱은 첫 통지를 기록한 날을 도달일로 본다(`engine.py:77-78`). 실제로 업체에 닿은 날은 확인하지 않는다. 같은 방식의 최근 사례를 더 찾으면 이 표에 추가한다.
- 업체가 "해지일은 빼야 한다"고 하면 통화 준비 카드(`data/templates/call_card.txt`)의 대응 문장을 쓴다. 차이는 하루치 금액이다.
- 1~3번(단위, 부가상품, 보증금)은 아직 코드에 없다. 2단계에서 테스트를 먼저 쓰고 `rules.py`에 넣는다.

## 반론 유형과 대응 근거 (초안)

| 업체 답장 유형 | 대응 방향 | 인용할 근거 |
|---|---|---|
| 무응답 | 기한 경과 후 재요청, 이어서 내용증명 | 방문판매법 제31조, 제32조 |
| "환불 불가 상품이다" | 계속거래는 언제든 해지할 수 있음을 안내 | 방문판매법 제31조 |
| "정상가 기준으로 차감한다" | 실제 결제금액 기준 계산을 요청, 다툼 시 1372 연결 | 확인 필요 |
| "방문해야 처리된다" | 해지 의사는 이미 도달했음을 알리고 서면 처리를 요청 | 고시 제5조 제1항 |
| 법정액보다 적은 금액 제시 | 계산 내역을 제시하고 차액을 요청, 하한선(`floor`, 비워 두면 사건을 열 때의 예상 환불액) 미만이면 경고 | 고시 (10% 상한) |
| 법정액 이상 제시 또는 수용 | 합의 내용 확인 문안으로 넘어감 | 없음 |
| 표에 없는 주장 | 단정하지 않고 "확인 후 다시 연락드리겠다"로 답함 | 없음 |

- 답장 유형은 화면이 읽은 결과를 사용자가 확정한 뒤에 기록된다(#73, `/api/replies/read`). 자동 판단만으로 합의 같은 단계가 생기지 않는다.
- 소비자 사정에서 반박을 되풀이하지 않는다(#75): 반박 문안을 `max_counters`(2, `data/policy.json`)번 보냈는데도 업체가 받아들이지 않으면 내용증명(`certified_mail`), 그 뒤에도 받아들이지 않으면 1372(`go_1372`)로 간다(`engine.next_action`). 이 횟수는 법에 정한 것이 아니라 앱이 정한 값이다. 하한선보다 적은 제시액이면 넘어가는 단계에서도 경고를 띄운다(`test_engine_paths.py::test_low_offer_after_max_counters_still_warns_and_good_offer_can_be_confirmed`). 내용증명 2항은 무응답과 거절 경로에 함께 쓰도록 "현재까지 환불을 받지 못하였습니다"로 바꿨다(#75).
- 업체 사정에서 반박을 한 번 보낸 뒤에도 업체가 거절하거나 희망 금액보다 적게 제시하면 내용증명을 건너뛰고 1372로 간다(#160). 하한선 미만 경고는 유지하고, 희망 금액 이상을 제시하면 합의 확인으로 간다. 답이 없으면 기한에 따라 재요청 → 내용증명 → 1372 순서로 간다. 이 분기는 앱이 정한 절차다. 답장 화면에서는 반박과 1372 안내 때 해당 유형의 조정례를 볼 수 있다(`Respond.tsx:132-133`). 한계: 반박 뒤 제시액이 하한선 이상이고 희망 금액 미만이어도 엔진은 1372로 보내고 이유 문구는 "반박 뒤에도 받아들이지 않아요"다(`engine.py` `next_action`). 합의 기록은 그대로 가능하다. 이 경우 문구를 따로 두는 것은 A 확인 사항이다.

## 계산 범위와 근거 요약의 성격

- **계산은 사용자가 고른 해지 이유(내 사정·업체 잘못)를 기준으로 한다.** 앱은 업체 귀책 여부를 판정하지 않는다. 업체 잘못을 고르고 유형을 선택하면(`Intake.tsx`, #154), 해당 사유가 인정된다는 조건으로 위약금 0원의 예상 환불액을 계산한다. 화면은 위약금이 0원이고 서버가 같은 날짜의 소비자 사정 환불액(`disputed_refund`)을 준 경우에만 영수증과 시작 버튼을 보인다. 업체가 다투면 위약금이 공제될 수 있다는 안내와 함께 그 금액을 보여 준다. 이용분·부가상품·보증금 계산은 두 경우에 같다.
- 업체 사정으로 시작한 사건은 고른 유형을 계약에 저장한다. 첫 통지와 위약금 반박 등은 해당 사건의 고정 양식을 사용한다. 비슷한 조정례는 참고로 볼 수 있고, 업체가 완전히 문을 닫아 연락이 안 되는 경우에는 문자 대신 1372에 상담하라고 안내한다. 업체 사정 계산을 받지 못하면 사건을 시작하지 않고 1372 안내와 사실 정리(`FaultSummary.tsx`)를 보여 준다. 상담용 사실 정리에는 사용자가 입력한 계약 정보와 설명만 넣는다.
- G4·G5는 사업자 귀책 없는 해지에서 위약금을 공제할 수 있다는 근거다. 업체 잘못일 때 0원으로 계산하는 것은 아래 절에 적은 적용 방식이다. 업체 귀책을 이유로 10%를 더하는 배상은 근거 표에 들어 있지 않으므로 계산과 업체에 보내는 문안에 적용하지 않는다. R32의 배상은 환급 지연에 관한 것이다.
- **업종은 헬스·피트니스업과 요가·필라테스업만 다룬다.** 위약금 기준(총계약대금의 10%)이 확인된 업종이 이 둘이다. 근거 확인 화면이 업종을 묻고, 그 밖의 업종이면 계산 금액·문안 대신 1372 상담을 안내하며 사건을 열지 않는다(`Intake.tsx`).
- `rules.json` 요약은 원문을 줄인 문장이고, 끝에 붙은 "요청할 수 있다", "단정하지 않는다" 같은 말은 원문이 아니라 앱이 근거를 쓰는 방식에 대한 지침이다.

## 업체 잘못일 때의 계산 근거 (2026-11-21, C)

팀 논의(2026-11-21): 업체 잘못이어도 '내 사정'과 같이 문자·전화로 협상하고, 거절당하면 1372로 넘어가며, 업체 잘못이면 얼마를 받을 수 있는지 보여 주자는 의견이 나왔다. 계산은 "위약금을 빼지 않고 이용분만 뺀다"는 안이다. 아래는 업체 사정 계산과 문안을 구현할 때 대조한 근거다(위 "계산 범위"). 이번 제출 범위로는 계산과 문안, 접수 화면, 1372 화면을 제안했다. 준비물 ZIP과 10% 배상 계산은 다음 단계 후보로 두었다. 이 구분이 팀의 최종 결정과 같은지는 A 확인이 필요하다. 업체 사정 계산과 양식은 같은 변경에 담았다. 접수와 1372 화면은 #154에서, 답장 화면의 비슷한 사례는 #160에서 들어왔다.

**위약금 0원: 근거 표의 조문으로 설명한다(반대해석, 아래)**

| 근거 | 내용 | 근거 표 |
|---|---|---|
| 고시 제4조 제1항 | 사업자의 귀책사유 **없이** 해지된 경우에 위약금을 청구할 수 있다 | G4 |
| 고시 제5조 제1항 | 환급액은 계약대금에서 이용분, 부가상품, "제4조에 따른 위약금"을 뺀 나머지다 | G5 |
| 방문판매법 제32조 | 위약금·환급 규정이 사업자 책임 없는 해지를 전제로 한다. R32 요약은 "사업자 잘못으로 해지하는 경우에는 이 조문만으로 위약금 공제를 인정하지 않는다"고 적는다(조문 문구가 아니라 요약에 쓴 해석) | R32 |
| 고시 제4조 제2항 | 제1항에 따른 사업자의 의무 이행 여부에 다툼이 있으면 **사업자가 입증**해야 한다 | G4 (입증 대상은 제1항에 따른 의무 이행 여부) |

- 그래서 업체 잘못일 때의 식은 `max(총계약대금 − 이용분 − 부가상품 가액, 0) + 보증금`(위약금 0)이다. 0원 아래로 내려가지 않게 하고 보증금을 따로 더하는 것은 지금 식과 같다.
- "귀책이 없을 때만 청구할 수 있다"를 "귀책이 있으면 청구할 수 없다"로 읽는 것은 반대해석이다. 조정례에서는 업체 쪽 사정이 다퉈진 조정례 7개 중 6개(첫 행은 계약 3건을 묶은 조정례 하나다)에서 위약금을 공제하지 않았고, 소비자 사정으로 본 13849만 공제했다. 다만 각 사건의 판단 이유는 달랐고, 여섯 건이 이 반대해석을 그대로 적용했다는 근거는 아니다(아래 "업체 잘못 유형별 조정례"). 변호사 검토는 받지 않았다.
- **고시 제4조 제2항은 국가법령정보센터 정본으로 확인했다**([공정거래위원회고시 제2019-9호](https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000183832), 2019. 11. 19. 시행, 2026-11-21 C 확인). 원문: "제1항에 따른 사업자의 의무 이행 여부에 대하여 다툼이 있는 경우에는 사업자가 이를 입증하여야 한다." 처음에 본 korea.legal 사본과 문구가 같다. 입증 대상은 "제1항에 따른 사업자의 의무 이행 여부"다. 업체가 잘못을 부인하는 모든 경우에 쓰는 일반 규칙이 아니라, 그 의무를 이행했는지 다툼이 있을 때 업체가 입증한다는 범위로만 쓴다. 문안과 화면 설명도 이 범위를 넘겨 "업체가 다 증명해야 한다"고 쓰지 않는다. G4 요약에는 이 범위로 제2항을 보강했다. 업체 사정 계산 결과는 위약금 근거로 G10 대신 G4를 가리킨다.
- 업체 잘못이 인정될지는 별개다. 사용자가 '업체 잘못'을 골라도 조정에서는 13849처럼 소비자 사정으로 볼 수 있다. 그래서 금액을 보여 준다면 "업체 잘못으로 인정되면"이라는 조건을 함께 보여야 한다.

**10%를 더 받는 근거: 있지만 조건이 붙는다. 앱 계산에는 넣지 않는다**

- **소비자분쟁해결기준(체육시설업)**: 사업자 귀책으로 해지하면 이용분을 빼고 이용료의 10%를 더한다. 조정례 11731·13984가 이 기준으로 10%를 더했다. 다만 합의·권고의 기준이고, 최신 고시 번호와 문구는 원문으로 확인하지 못했다. `rules.json`에 없다.
- **체육시설법 제22조 제1항 제4호 나목, 시행령 별표 3의2**: 업자의 폐업·휴업 등으로 영업을 계속할 수 없을 때 반환한다. 별표 3의2는 이용 개시 전이면 `이용료 + 이용료의 1/10`, 개시 후면 `이용료 − 이용분 + 이용료의 1/10`으로 나눈다(가목 이용자 사정은 1/10을 뺀다. 개시 전·후 구분은 Codex 교차 검증 보고이고, C는 별표 원문을 대조하지 못했다). 반환 사유가 생긴 날부터 3영업일 안에 반환하고, 늦으면 연 15% 지연이자가 붙는다(시행령 제21조의3). 조건이 있다.
  - 반환 사유와 금액을 따로 **약정하지 않았을 때만** 적용된다. 계약서에 환불 조항이 있다고 바로 빠지는 것은 아니고, 그 조항이 반환 사유와 금액을 정했는지에 달려 있다.
  - 사유가 폐업·휴업 "등"이다. 강사 변경이나 수업 축소에 쓸 수 있는지는 정해지지 않았다.
  - B는 1년 미만 계약, 신고 체육시설업(헬스장 해당, 요가·필라테스는 목록에 없음) 조건도 있다고 정리했다. Codex 교차 검증은 '1년 미만'이 법 제2조 제5호의 일반이용자 정의에서 나온다고 보고했다(법제처 법령해석 인용). C는 이 조문을 직접 대조하지 않았다. 해당 업종인지는 따로 확인이 필요하다.
  - 확인한 곳: [법 제22조 사본](https://korea.legal/wiki/%ec%b2%b4%ec%9c%a1%ec%8b%9c%ec%84%a4%ec%9d%98-%ec%84%a4%ec%b9%98%e3%86%8d%ec%9d%b4%ec%9a%a9%ec%97%90-%ea%b4%80%ed%95%9c-%eb%b2%95%eb%a5%a0-%ec%a0%9c22%ec%a1%b0/)(검색 결과 문구), [시행령 별표 3의2 사본](https://korea.legal/wiki/%ec%b2%b4%ec%9c%a1%ec%8b%9c%ec%84%a4%ec%9d%98-%ec%84%a4%ec%b9%98%e3%86%8d%ec%9d%b4%ec%9a%a9%ec%97%90-%ea%b4%80%ed%95%9c-%eb%b2%95%eb%a5%a0-%ec%8b%9c%ed%96%89%eb%a0%b9-%eb%b3%84/)(2024. 8. 27. 개정), [시행령 제21조의3 사본](https://korea.legal/wiki/%ec%b2%b4%ec%9c%a1%ec%8b%9c%ec%84%a4%ec%9d%98-%ec%84%a4%ec%b9%98%e3%86%8d%ec%9d%b4%ec%9a%a9%ec%97%90-%ea%b4%80%ed%95%9c-%eb%b2%95%eb%a5%a0-%ec%8b%9c%ed%96%89%eb%a0%b9-%ec%a0%9c21/), [문화체육관광부 보도자료](https://www.mcst.go.kr/site/s_notice/press/pressView.jsp?pSeq=15445). 모두 정본이 아니다. Codex 교차 검증이 본 국가법령정보센터 링크: [법 제22조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1032754577), [시행령 제21조의3](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=132032).
- 그래서 10%는 계산하지 않고 문자에도 넣지 않는다. 업체가 거절해 1372로 넘어갈 때 "이 기준을 물어보라"고 안내하는 쪽이 안전하다.
