① 활용 AI 모델·도구
[서비스] OpenAI gpt-6.1-terra(Chat Completions API): 업체 답장 읽기(8가지 유형과 제시 금액), 답장 분석(주장마다 근거 표 항목 연결), 상황별 조언, 보낼 문자 말투 다듬기, 계약서 사진 읽기(9가지 값과 확신도). 2026-11-15에 gpt-6-luna·gpt-6.1-sol·gpt-6-astra와 같은 답장 5건으로 비교해 골랐다.
[개발] Claude Code(Anthropic): 세 트랙 모두 코드·테스트·문서 작성, 평가 실행과 기록, PR 리뷰 초안, 자료 조사. Codex(OpenAI): C 트랙 변경의 교차 검증.
[콘텐츠] 마스코트(딱따구리) 그림: ChatGPT 웹으로 생성(A 트랙), 서비스 화면과 시연 영상에 사용. 시연 영상 배경음 「Afterglow Circuit」: OpenAI gpt astra로 생성(C 트랙). 모의 계약서 이미지와 효과음: 팀이 양식을 정하고 Claude Code로 제작.

② AI 활용 범위와 팀의 기여
- 팀이 정한 것: 문제 정의(말을 꺼내기 어려워 환불을 미루는 청년), 서비스 범위, "계산은 코드, 읽기와 설명은 AI, 보내는 것은 사람"이라는 구조, 사용할 모델, 유료 실행 승인, PR 병합 여부.
- 서비스: 환불액은 규칙 코드만 계산하고, 업체에 보내는 글은 AI가 초안을 쓰고 팀이 검토해 확정한 고정 양식이다. AI는 검사를 통과할 때만 그 글의 말투(어미)를 다듬는다. AI가 업체에 보낼 글을 직접 쓰게 한 실험(글 9건)을 팀이 보고 이렇게 정했다.
- 개발: 코드, 프롬프트, 문서 초안은 대부분 AI가 썼다. 사람은 방향을 정하고 결과를 읽고 고칠 점을 냈다. 변경은 PR로 올리고 다른 트랙 담당자가 검토했다(A→B→C→A). 근거 표의 법령·고시는 사람(C)이 국가법령정보센터 원문으로 확인했다. 배포된 화면은 사람이 직접 써 보고 문제를 찾았다(기다림 표시 없음, 첫 문자부터 법 조문을 듦 등).
- 평가 자료: 어려운 답장 100건의 문장과 정답 초안은 서비스 프롬프트를 보지 않은 AI가 쓰고 판정 기준은 사람이 정했다. 역할 카드 답장 20건 중 8건은 사람이 직접 썼다. 간이 설문(응답 17건)은 사람이 집계했다.

③ API·외부 데이터·오픈소스
- API: OpenAI API(gpt-6.1-terra). 그 밖 없음.
- 외부 데이터: 방문판매법과 공정위 「계속거래 등의 해지·해제에 따른 위약금 및 대금의 환급에 관한 산정기준」(근거 표 11건), 한국소비자원·소비자24 공개 조정·상담 사례(화면 참고 사례 7건. 공개 사례 185건을 모았고, 그중 81건은 원문을 읽고 요지를 기록했다), 한국소비자원·문화체육관광부 통계(소개서). 실제 개인정보는 쓰지 않았다. 평가와 시연에는 가상 계약서와 지어낸 답장만 썼다.
- 오픈소스: React, TypeScript, Vite, Tailwind CSS, shadcn/ui·Base UI, FastAPI, Pydantic, Pretendard 글꼴. 상세 출처·링크·라이선스는 소개서 지정 별첨의 「활용한 외부 자원·출처」 표에 적었다.

④ 검증 및 한계 대응
- 코드: 서버 테스트 365개(API 키 없이 가짜 LLM)와 브라우저 화면 흐름 점검 179항목을 통과했다. 실제 모델 평가는 실행 커밋, 호출 수, 한계를 같이 기록했다(누적 API 비용 2.35달러).
- AI 결과: 어려운 답장 100건 유형 98/100(AI 없는 키워드 판단 42/100), 표기를 바꾼 답장 435건 435/435, 조언 10건 필수 근거 10~11/11·근거 표 밖 근거 0건, 계약서 이미지(깨끗한 내보내기 이미지)는 프롬프트를 고칠 때 본 12장 60/60, 처음 본 10장 50/50, 월 단위 5장 25/25(기본 다섯 값). 환불액은 가상 계약 27건과 실제 조정 사례 5건(4건 원 단위 일치, 1건 22원 차이)으로 대조했다.
- 설계로 막은 것: AI 출력에서 정해진 형식으로 적힌 금액을 서버 계산값과 대조하고, 근거 표에 없는 항목이나 글 속 법령 이름, 정해 둔 압박 표현이 있으면 코드가 버린다. AI가 읽은 답장은 사용자가 "맞아요"를 눌러야 기록된다. 근거를 못 찾은 주장에는 "확인 필요"를 붙이고, 분석·조언은 "참고용"으로 표시한다. AI가 멈추거나 하루 상한(100회)을 넘으면 키워드 판단과 버튼으로 끝까지 진행된다.
- 주요 오류와 보완: 다른 사람이 쓴 답장 20건에서 미루는 답을 수용으로 읽은 위험한 오답 1건이 나왔다. 사용자 확정 단계가 막아 바로 합의되지 않으며, 이 자료에 맞춰 프롬프트를 고치지는 않았다. 정상가 주장과 함께 온 금액을 놓친 문제, 0원 제시를 버린 문제는 고쳤다. AI가 요약한 사례 2건은 원문과 대조해 틀린 판단을 고쳤다.
- 남은 한계: 조언의 틀린 해석이나 단정은 코드 검사로 못 잡는다(개시 전 해지 1건에서 위약금을 단정). 휴대폰으로 찍은 사진과 처음 보는 사용자의 사용성은 아직 재지 않았다. 업체 잘못인지는 판정하지 않고 조건부 금액과 1372 상담으로 안내한다. 어려운 답장 100건의 정답은 사람이 4건만 확인했다.
